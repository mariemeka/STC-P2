# STC-P2 — Sous-titrage collaboratif

## Objectif
Développer un système de sous-titrage collaboratif permettant de fusionner les contributions de plusieurs sous-titreurs pour produire un fichier final cohérent.

## Data Flow
Entrée :
- contributions de plusieurs sous-titreurs

Traitement :
- fusion des contributions (MSA)

Sortie :
- sous-titre final
- fichier SRT / VTT

## État du projet
Projet en phase de conception.
